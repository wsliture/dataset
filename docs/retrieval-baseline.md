# 首轮本地检索基线

使用固定版本 `BAAI/bge-m3`、1024 维 CPU 推理和真实 PostgreSQL/pgvector。评估库包含一个已发布案例「控制器报警」，关联两段源文和三段测试需求。候选池上限为 100，最低余弦相似度为 0.55，返回上限为 5。

| 检索方式 | 前五条命中率 | 无匹配误返回率 |
| --- | --- | --- |
| 纯关键词 | 4/4（100%） | 1/2（50%） |
| 纯语义 | 4/4（100%） | 1/2（50%） |
| 混合检索 | 4/4（100%） | 1/2（50%） |

| 查询 | 预期 | 三种方式的实际结果 |
| --- | --- | --- |
| CAN-01 | 命中完整接口标识 | 返回「控制器报警」 |
| 控制器进入复位模式后如何初始化？ | 命中复位后进入初始化状态的条款 | 返回「控制器报警」 |
| 超过 80℃ 时控制器应触发超温告警 | 命中温度条件改写 | 返回「控制器报警」 |
| TEMP-02 在八十摄氏度整时是否必须报警？ | 命中可用于核对严格大于边界的条款 | 返回「控制器报警」 |
| 如何校准光学望远镜的主镜？ | 空列表 | 空列表 |
| CAN-01 收发器的总线终端电阻值是多少？ | 空列表，源文仅描述接口的复位行为 | 误返回「控制器报警」 |

复测时按照[启动说明](../README.md)启用 `DATASET_TEST_REAL_MODEL=1`。API 集成测试使用同一组预标注查询输出各路指标及失败样例。该基线覆盖接口、同义改写、数值边界和无匹配场景，Phase 2 接入门槛待更大规模评估后确定。
